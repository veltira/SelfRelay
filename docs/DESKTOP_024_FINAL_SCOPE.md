# SelfRelay Desktop 0.2.4 — final delivery scope

This release closes the final CoderCup Desktop usability and trust issues:

- Whisper transcription runs in-process; no whisper-cli.exe, cmd.exe or PowerShell child process is part of the product flow.
- Recovery-window close/minimize is non-destructive and the recovery window is restorable from the Windows taskbar.
- History is a durable timeline grouped by application/workset and any checkpoint can be reopened.
- Audio can be played and transcribed from History.
- A local setting controls whether resolved checkpoints are archived as project context or removed after use.
- Official CoderCup deliverables remain SelfRelay-Chrome.zip, SelfRelay-Setup.exe and the video link.
